#### Description

Lists running applications with a regular activation policy (i.e. apps with a Dock icon / menu bar, not
background agents). Does not require any special permission.

#### Usage

```bash
aux4 computer mac apps
```

#### Example

```bash
aux4 computer mac apps
```

```json
{"apps":[{"active":true,"bundleId":"com.apple.TextEdit","hidden":false,"name":"TextEdit","pid":1234}]}
```
