#### Description

The `computer-mac` AI skill teaches an agent to use a Mac's apps with `aux4 computer mac` while a person is using the
same Mac: the loop (state, find, OCR fallback, `screenshot --annotate` for vision, act by element ref / menu / set /
select, wait), what works in the background and when the foreground fallback happens, coordinate rules, the stop
switch and action log, permissions and troubleshooting.

#### Usage

```bash
aux4 ai skill computer-mac prompt
```

#### Example

```bash
aux4 ai skill computer-mac prompt
```
