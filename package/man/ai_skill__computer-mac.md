#### Description

**Deprecated** — kept for one release. The `computer-mac` skill is now an alias of the `aux4/computer` AI skill
(`aux4 ai skill computer prompt`): the generic method for agents (state, find, OCR fallback, `screenshot --annotate`,
act by element ref / menu / set / select, wait; background and foreground; coordinates; stop switch and action log)
followed by this package's macOS notes (`aux4 computer mac notes`: permissions, background limits, data-loss and OCR
gotchas, Retina coordinates, label differences).

#### Usage

```bash
aux4 ai skill computer prompt
```

#### Example

```bash
aux4 ai skill computer-mac prompt
```
