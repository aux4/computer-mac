#### Description

The `skill` command lists the AI skills installed as aux4 packages: methods an agent reads before using a
capability. This package adds `computer-mac`.

#### Usage

```bash
aux4 ai skill <name> prompt
```

#### Example

```bash
aux4 ai skill list
```

```text
computer-mac  -  Use a Mac's apps in the background: state, find, ocr, screenshot --annotate, act by ref, wait; background limits, coordinates, the stop switch
```
